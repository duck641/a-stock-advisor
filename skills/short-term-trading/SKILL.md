# 短线交易规则

## 任务目标
- 本 Skill 用于：提供 A 股短线交易（持股 1-5 个交易日）的完整规则体系
- 能力包含：入场规则、出场规则、仓位管理、止损策略、选股条件、盘口分析
- 触发条件：用户提到"短线"、"超短线"、"打板"、"日内"、"T+1"、"快进快出"、"短线操作"等关键词时

## 短线交易核心原则

### 选股条件
1. **成交量原则**：当日成交量 > 5日均量的 1.5 倍，无量不参与
2. **换手率原则**：换手率 3%-10% 为活跃区间，低于 2% 不参与
3. **流通市值**：30亿-200亿之间最佳，大盘股短线弹性差
4. **涨幅限制**：不追高，开盘涨幅超过 5% 的不参与（打板策略除外）
5. **趋势位置**：股价在 20 日均线上方，且 5 日均线向上

### 入场规则
1. **突破入场**：股价放量突破前一日高点或近期平台，成交量 > 日均量 2 倍
2. **回踩入场**：股价回踩 5 日均线不破，缩量企稳后入场
3. **开盘入场**：高开 1%-3% 且集合竞价量能充足（>昨日成交量的 5%），开盘后 5 分钟不回落
4. **强势股回调**：强势股首次回调至 5 日线或 10 日线，缩量止跌

### 出场规则
1. **止盈出场**：
   - 目标 5%-8% 分批止盈：达 5% 减半仓，达 8% 清仓
   - 连续拉升后出现长上影线 → 立即止盈
   - 开盘冲高回落破分时均线 → 卖出
2. **止损出场**：
   - 买入后跌破买入价的 3% → 无条件止损
   - 买入后 3 个交易日不涨 → 离场
   - 大盘跳水（跌幅 > 2%）→ 不论盈亏先出
3. **时间止损**：持股超过 5 个交易日未达预期 → 离场

### 仓位管理
1. **单票仓位**：单只股票不超过总资金的 20%
2. **分批建仓**：首次建仓 50%，确认走势后加仓 30%，剩余 20% 机动
3. **持仓数量**：同时持仓不超过 3 只股票
4. **大盘配合**：
   - 大盘上升趋势 → 满仓操作（上限 80% 总仓位）
   - 大盘震荡 → 半仓操作（上限 50% 总仓位）
   - 大盘下降趋势 → 空仓或轻仓（上限 20% 总仓位）

### 技术指标参考
1. **KDJ**：J 值 < 20 为超卖区（买入参考），J 值 > 80 为超买区（卖出参考）
2. **MACD**：15 分钟/30 分钟 MACD 金叉为短线入场信号
3. **成交量**：缩量回调 + 放量拉升为健康走势
4. **分时图**：
   - 分时均线上方运行 → 强势，持股
   - 分时均线下方运行 → 弱势，考虑卖出
   - 分时均价线作为当日多空分界线

### 盘口观察要点
1. **买卖盘口**：买一至买五堆大单不一定是护盘，可能是出货托盘
2. **大单成交**：连续大单买入但股价不涨 → 疑似对倒，谨慎
3. **内外盘比**：外盘 > 内盘 2 倍且股价上涨 → 上涨有效
4. **分时量能**：拉升时有量配合才可信，无量拉升多为诱多

### 风险警示
1. **永不补仓**：短线被套永远不加仓摊薄，严格执行止损
2. **逆势不做**：大盘下跌趋势中不做短线
3. **业绩期回避**：财报披露前 3 个交易日不参与
4. **下午少操作**：除非有明确信号，下午 2:30 前不建新仓
5. **纪律第一**：到了止损位就出，不找理由，不心存侥幸

## 操作步骤

1. **识别触发条件**：用户输入中包含短线相关关键词
2. **获取数据**：调用 get_realtime_quote / get_stock_daily_history / get_technical_info 获取目标股票数据
3. **检查选股条件**：按"选股条件"逐条检查（成交量、换手率、市值、涨幅、趋势位置）
4. **判断入场机会**：按"入场规则"判断是否符合
5. **设定出场计划**：进入时即确定止盈位和止损位
6. **执行仓位管理**：按"仓位管理"规则决定仓位大小
7. **给出建议**：完整说明操作建议 + 理由 + 风险提示 + 严格的买卖点

## 注意事项
- 短线交易的核心是纪律，提示用户严格执行止损
- 不推荐打板策略给散户
- 单只股票短线操作不超过 5 个交易日
- 交易时间为 A 股交易时段（9:30-11:30, 13:00-15:00）
- 所有建议基于技术分析，不构成投资建议

## 三种选股策略

### 策略一：打板策略（高风险高收益）

核心逻辑：在股票涨停瞬间或封板前买入，博次日高开溢价或连板行情。

**买入条件**：
1. 只打首板或二板，三板以上坚决放弃
2. 必须是板块内最先涨停的前 2 只（龙头或龙二）
3. 封板前换手率要充分：底部首板换手 > 5%，二板换手 > 10%
4. 封单量 > 当日成交量的 30%（封单厚才安全）
5. 不打一字板（买不进，进去就是坑）
6. 不打尾盘板（14:30 后涨停），早盘 10:30 前封板的质量最高

**仓位管理**：单票 10%-15%。打板失败次日往往计提 -5% 以上，必须轻仓控制风险。

**卖出规则**：
1. 次日不涨停 → 竞价或开盘即砸，不犹豫
2. 次日涨停但封单减弱 → 盘中开板即走
3. 次日高开 3%-5%，但开盘 5 分钟内走弱跌破均价线 → 立即止盈
4. 次日低开 → 竞价直接砍，不等 -3% 止损线

> 口诀："打板不打杂毛，封单不大不打，尾盘板不打"

### 策略二：强势股低吸（中等风险）

核心逻辑：选近期有过涨停或连续大阳线的强势股，等它回调到关键均线时买入，博第二波反弹。

**选股前提**：近 5-10 日内有过涨停或连续大阳线（累计涨幅 > 15%），当前处于首次回调阶段。

**买入条件**：
1. 回调缩量：近 3 日成交量 < 涨停日成交量的 60%（说明主力没跑）
2. 回踩 MA5 或 MA10 不破（盘中刺破但收盘收回算有效）
3. 不跌破涨停日起涨点（趋势线支撑位）
4. 买点时间：下午 14:30 后确认当天跌不动（分时图在均价线上方站稳）再进场
5. 当日大盘不暴跌（跌幅 < 0.5%）

**仓位管理**：单票 15%-20%。

**卖出规则**：
1. 反弹到前高附近（距前高 3% 以内）止盈半仓
2. 再出大阳线或涨停但封不住 → 清仓
3. 跌破止损线（买入价的 -3% 或跌破 MA10）→ 立即走
4. 横盘 3 天不涨 → 时间止损，离场

> 口诀："放量涨，缩量调，踩均线，尾盘进"

### 策略三：突破策略（稳健型）

核心逻辑：股价在横盘箱体震荡后，放量突破前期高点时跟进，博趋势启动。

**选股前提**：股价处于横盘箱体震荡（10-20 个交易日），箱体高低差 < 15%。

**买入条件**：
1. 当日放量突破箱体前高：成交量 > 近 20 日均量的 1.5 倍
2. 突破幅度 > 3%（排除假突破）
3. 板块共振：所属板块当日涨幅前 10，且至少有 3 只同概念股涨幅 > 5%
4. 突破时间最好在上午 10:30-11:00（早盘突破比尾盘突破更可靠）
5. 突破时分时图持续在均价线上方，不冲高回落

**仓位管理**：单票 15%-20%。

**卖出规则**：
1. 突破后 3 天内继续上攻 → 持有到加速大阳线时分批止盈
2. 3 天内不能继续上攻（横盘或回落）→ 时间止损，离场
3. 回踩跌破突破点（前高价位）→ 无条件止损
4. 止盈目标：5%-8%（突破策略空间有限，不贪）

> 口诀："放量突破看板块，三天不攻就得跑，回踩破位不能留"

## 使用示例

### 示例1：短线入场判断
```
用户："赛力斯能做短线吗？"
分析步骤：
1. 获取实时行情和技术数据
2. 检查成交量是否达标（> 5日均量 1.5 倍）
3. 检查换手率是否在 3%-10%
4. 判断趋势位置（20 日线上方 + 5 日线向上）
5. 是否符合入场规则（突破/回踩/开盘）
6. 设定止盈 5%-8%，止损 3%
7. 给出仓位建议和买卖点
```

### 示例2：持仓管理
```
用户："昨天买了富春环保，今天怎么操作？"
分析步骤：
1. 查看当前持仓盈亏状态
2. 检查分时图走势（是否在分时均线上方）
3. 检查是否触发止盈/止损条件
4. 按规则决定持有/加仓/卖出
```
