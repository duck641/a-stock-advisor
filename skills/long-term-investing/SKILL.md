# 长期投资规则

## 任务目标
- 本 Skill 用于：提供 A 股长期投资（持股 6 个月以上）的完整选股与持有规则体系
- 能力包含：选股标准、估值方法、建仓策略、持仓管理、卖出规则、风险控制
- 触发条件：用户提到"长线"、"价值投资"、"长期持有"、"蓝筹"、"白马"、"股息"、"捂股"、"定投"、"价值低估"等关键词时

## 选股标准

### 行业要求
1. 优先选择处于成长期或成熟期的行业，避开衰退行业
2. 行业龙头或细分赛道龙头，市占率持续提升
3. 行业具有长期需求支撑（消费、医药、科技、新能源、高端制造）
4. 政策支持的行业优先（符合国家产业升级方向）

### 基本面门槛
1. **ROE**：连续 3 年 ROE > 15%，且保持稳定或上升趋势
2. **毛利率**：> 30%（消费品 > 40%，科技 > 50%）
3. **净利率**：> 10%
4. **营收增长**：连续 3 年营收正增长，复合增长率 > 10%
5. **净利润增长**：连续 3 年净利润正增长，复合增长率 > 15%
6. **资产负债率**：< 60%（金融企业除外）
7. **经营性现金流**：连续 3 年为正，且覆盖净利润

### 估值要求
1. **市盈率（PE）**：低于行业历史中位数，或低于国际同行的 80%
2. **市净率（PB）**：< 3（轻资产行业可放宽）
3. **股息率**：> 2%（熊市配置时 > 3% 更佳）
4. **PEG**：< 1.5（市盈率/净利润增长率）
5. **估值分位**：当前估值处于近 5 年估值的 30% 分位以下为佳

### 管理层与企业质量
1. 管理层持股比例高（> 10%），利益与股东一致
2. 有持续分红历史（连续 5 年以上分红）
3. 无重大负面舆情或财务造假历史
4. 有清晰的发展战略和竞争优势（护城河）

## 建仓策略

### 分批建仓法
1. **首次建仓**：计划仓位的 30%，在估值合理或低估时入场
2. **加仓条件**：股价低于首次建仓价的 10% → 加仓 20%
3. **二次加仓**：股价再跌 10% → 再加仓 20%
4. **剩余仓位**：保留 30% 机动，应对极端下跌或更好的机会
5. **总建仓期**：3-6 个月内完成，不急于一次性满仓

### 最佳买入时机
1. 大盘大幅调整（跌幅 > 20%）后
2. 个股因短期利空暴跌但基本面未恶化
3. 财报季后，业绩超预期但市场未充分反应
4. 行业周期性低谷，龙头公司被错杀

## 持仓管理

### 仓位分配
1. **单票上限**：单只股票不超过总资金的 30%
2. **行业上限**：单一行业不超过总资金的 40%
3. **持仓数量**：3-8 只股票构成投资组合
4. **仓位基准**：
   1. 估值低估区 → 满仓（总仓位 80%-90%）
   2. 估值合理区 → 中性仓位（总仓位 50%-70%）
   3. 估值高估区 → 减仓（总仓位 30%-50%）
   4. 估值泡沫区 → 轻仓（总仓位 < 20%）

### 持有原则
1. 只要基本面没有恶化，长期持有
2. 不因短期波动（< 20%）卖出
3. 每季度检视一次持仓股的基本面
4. 对比持有机会成本，有更好的标的才换仓

## 卖出规则

### 基本面卖出（必须卖出）
1. ROE 连续 2 年下滑至 10% 以下
2. 营收连续 2 年负增长
3. 核心竞争优势丧失（新技术颠覆、市场份额大幅下滑）
4. 管理层出现重大诚信问题
5. 行业政策发生根本性不利变化

### 估值卖出（择机卖出）
1. PE 达到历史估值 90% 分位以上 → 减半仓
2. PE 达到历史估值 95% 分位以上 → 清仓
3. 市值远超国际同行合理估值 → 分批卖出

### 机会成本卖出
1. 发现更优标的（确定性更高、空间更大）→ 换仓
2. 持仓股增长逻辑兑现，空间已不大 → 卖出
3. 市场出现系统性机会（如债券收益率大幅上升）→ 调整配置

## 风险控制
1. 永久性损失风险 > 波动风险：基本面变坏才是真风险
2. 不因股价下跌而止损，只因基本面恶化而止损
3. 个股最大回撤超过 40% 时重新评估投资逻辑
4. 组合整体回撤超过 20% 时全面检视
5. 不使用杠杆或融资做长线投资

## 操作步骤

1. **识别触发条件**：用户输入中包含长线投资相关关键词
2. **初步筛选**：获取基本面数据（ROE、毛利率、净利率、营收增长、负债率）
3. **估值评估**：获取估值指标（PE、PB、股息率），判断估值分位
4. **行业判断**：分析所属行业的长期前景和政策环境
5. **建仓计划**：按分批建仓法制定买入计划
6. **风险提示**：说明最大回撤可能、持有周期预期、基本面变坏的警报信号

## 注意事项
- 长期投资的核心是选股和耐心，不预测短期涨跌
- 分红再投资是长期复利的重要来源
- 定期检视但不过度交易
- 所有建议基于基本面分析，不构成投资建议
- 长线不适合需要短期流动性的资金

## 三种选股策略

### 策略一：价值白马策略（最稳健，适合大多数人）

核心逻辑：选行业龙头，公司有持续赚钱能力，估值合理时买入，赚业绩增长和分红复利的钱。

**选股标准**：
1. ROE（净资产收益率）：连续 5 年 > 15%（赚钱能力强）
2. 毛利率：> 30%（有定价权，不是苦生意）
3. 净利润增速：近 3 年复合增长 > 10%（成长性）
4. 经营性现金流：为正且 > 净利润（赚的是真钱，不是白条）
5. 资产负债率：< 60%（财务安全）
6. 股息率：> 2%（有保底收益，跌了也不怕）

**行业偏好**：消费（白酒、调味品、家电）、医药（创新药、医疗器械）、科技（半导体、软件龙头）、金融（保险、银行龙头）

**买入时机**：
1. PE（市盈率）处于历史估值 30% 分位以下（低估区域）
2. 或者大盘暴跌时（比如指数跌 20% 以上），白马股被错杀时买入
3. 分批建仓：先买 30%，跌 10% 加 30%，再跌 10% 加 40%

**卖出时机**：
1. PE 处于历史 70% 分位以上（高估了）
2. 公司基本面恶化（ROE 持续下滑、增速放缓）
3. 找到更好的标的换仓

**持有周期**：3-5 年起，甚至更长

**仓位建议**：单票不超过 20%，分散到 3-5 个不同行业

> 口诀："好公司好价格，长期持有等复利，大跌大买小跌小买"

### 策略二：成长股策略（中高风险高收益）

核心逻辑：选处于高增长赛道的小市值公司，行业渗透率低，空间大，赚公司从「小变大」的市值增长钱。

**选股标准**：
1. 行业空间：所处行业未来 3-5 年复合增速 > 20%（如 AI、新能源、创新药）
2. 营收增速：近 2 年营收增长 > 30%（跑得快）
3. 市占率：< 10%（还有很大提升空间）
4. 研发投入：占营收比例 > 5%（有技术壁垒）
5. 管理层：有股权激励，有行业经验，没减持黑历史
6. 市值：50 亿 - 300 亿（从小变大空间最大）

**行业偏好**：AI 应用、半导体国产替代、创新药、新材料、高端装备

**买入时机**：
1. 行业景气度向上时买入（政策支持、行业数据转好）
2. 个股回调到年线（MA250）附近获得支撑时买入
3. 不追高（PE 超过行业平均 2 倍以上等回调）

**卖出时机**：
1. 行业增速放缓（从 20% 降到 10% 以下）
2. 市值涨到千亿以上（空间变小了）
3. 竞争格局恶化（新玩家涌入、价格战）
4. 管理层大量减持

**持有周期**：2-3 年，等业绩兑现

**仓位建议**：单票不超过 15%，成长股波动大，分散到 5-8 只

> 口诀："赛道要对，增速要快，市值要小，格局要大"

### 策略三：困境反转策略（高风险高收益）

核心逻辑：选遭遇行业低谷或公司短期困难，但核心竞争力没丢的公司，在最低谷时买入，等基本面反转。

**选股标准**：
1. 曾是行业龙头，有品牌或技术护城河
2. 困难是「暂时的」（行业周期下行、政策利空、管理层动荡），不是「毁灭性的」（技术被颠覆、产品被淘汰）
3. 资产负债表健康：现金多、负债少（能扛过寒冬）
4. 行业出现见底信号（政策转向、产品价格企稳、库存下降）
5. 有催化事件（新管理层上任、新产品获批、行业政策放松）

**典型场景**：
1. 行业周期低谷：如猪周期底部的养猪龙头、化工周期底部的化工龙头
2. 政策利空后的修复：如反垄断后的互联网龙头、集采后的医药龙头
3. 黑天鹅事件：如瘦肉精事件后的双汇、塑化剂事件后的白酒

**买入时机**：
1. 行业最悲观时买入（利空出尽，股价横盘不再跌了）
2. 分批买：先买 20%，股价企稳加 30%，基本面确认反转加 50%
3. 非常左侧，需要极大的耐心和信心

**卖出时机**：
1. 行业景气度恢复正常，股价回到合理估值区间
2. 公司基本面确立反转后，估值修复完成（通常涨幅 50%-100%）
3. 发现判断错了（核心竞争力被毁），立即止损

**持有周期**：1-3 年，等基本面兑现

**仓位建议**：单票不超过 10%（反转可能不及预期，甚至失败），分散到不同行业

> 口诀："好公司遇麻烦，麻烦是暂时的，股价跌透了就是机会"

## 使用示例

### 示例1：价值选股评估

用户："贵州茅台适合长期持有吗？"

分析步骤：
1. 获取基本面数据（ROE、毛利率、净利率、增长趋势）
2. 获取估值指标（当前 PE、历史 PE 分位、股息率）
3. 判断行业前景（白酒行业、消费升级趋势）
4. 评估买入时机（当前估值水平是否合理）
5. 给出长期投资建议和仓位建议

### 示例2：持仓跟踪

用户："我持有的招商银行，年报出来了，看看还行不行？"

分析步骤：
1. 获取最新财务数据（ROE、营收增长、不良率）
2. 对比卖出规则中的基本面卖出条件
3. 重新评估估值水平
4. 给出持有/换仓建议
